# The Streaking of Isaac

Isaac Community Streaking Leaderboard.

## Local run

```bash
cp .env.example .env
cargo run
```

## Admin account

No public inscription, trusted members only on purpose.

Set/Update command:
```bash
cargo run --bin create_admin -- username password
```

## Features

Managing leaderboards. Inspired by [Leaderboard streaks Issac](https://docs.google.com/spreadsheets/d/1So2N0caOnTe7ctLg1OYEYg_8Eqc_ak03Vm4TXsgHG0c/edit?gid=2144039399#gid=2144039399)
