Categories

4 Goals

  1. Runs must form a cycle of 4 goals (chest,dark room,mother,the beast)
  2. You must keep the order of goals consistent throughout the streak(e.g. if you go for dark room-chest-mother-the beast you must achieve them in that specific order)

Random Boss

  1. Random pool usually has 4 goals (chest,dark room,mother, beast), but you can add other bosses such as Delirium.
  2. Player rolls a dice or spins a wheel at the start of each run to determine which boss eden goes to (show on stream to prove it)
  3. If you're in a situation where you got 0 keys on the first two floors during a mother run, you can:
    1. On a 4 Goals streak, you can do the goals from the next run instead (probably beast) and go for mother next run.
    2. Give the key via the console (spawn 5.30.1)
    (make sure there were no keys; if there was a key available somewhere, then you must continue the run and either use RKey or find an item that allows you to open the door that gives access to Corpse)

Other Streaks

  • There are various streaks,which are not so popular, but worthy of attention

6 Goals

  1. Runs must form a cycle of 6 goals (chest,dark room,mother,the beast,mega satan,delirium)
  2. You must keep the order of goals consistent throughout the streak

Delirium

  1. you can take any path (unless you specify that you must kill a specific boss first)

Hoarder

  1. you have to pick up every item you see and use all the pills you see (if it's known, you don't have to use it)
  2. if you have a choice of several items but can only take one, you have the right to choose the one you want (in a devil deal, if buying an item kills you, you can not to take it)
  • If in a Beast run, curse of the maze teleports you directly in the boss, you're allowed to give yourself a The Fool card with the console (spawn 5.300.1).
    This isn't allowed if you've already seen the marked skull or another teleport card on that floor and don't take it.

Random V1 & V2

  1. Random V1 corresponds to normal characters.
  2. Random V2 corresponds to tainted characters.
  3. The character is randomly selected directly in-game.

GameBreak Only

  1. For the full GB streak, you must kill the designated boss and establish the GB, if one of these two conditions is missing, the run is invalid.
  2. For a GameBreak to be counted as validated, you need to be able to release an unlimited quantity of resources, leading to the creation of unlimited piedestaux, which can be reroll an unlimited number of times.
  3. In the full GB streak, even if it's an eden blessing that gives you tmtrainer, you can remove it (unlike in the normal streak), but you can't remove this game to make another one, it must be played.
  4. If the GB is considered too long (for example, a GB with placenta), you must explain why the GB is valid (oral or written) and finish the game.
