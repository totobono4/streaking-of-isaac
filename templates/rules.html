Rules

Global rules

  1. The specified goal of the streak must be completed in a run. Streak counts after the ending/credits.
  2. Every run must be on hard.
  3. No Save & Quit abuse.
  4. Every run must be streamed.
  5. Mods that alter the gameplay(i.e. new rooms, mobs etc.) are forbidden.
  6. Streaks must be on full save file(dead god)
  7. All runs should have seeds visible on the screen (Rebirth Item Tracker, pause in the beginning or in the end of the run)

Notes

  • Submit your records through the record submission.
  • If you have any questions/suggestions about leaderboard message DobryyLisenok#9221
  • The rules may change over time

Additional categories

4Goals

  1. Runs must form a cycle of 4 goals(chest,dark room,mother,the beast)
  2. You must keep the order of goals consistent throughout the streak(e.g. if you go for dark room-chest-mother-the beast you must achieve them in that specific order)

Random Boss

  1. Random pool usually has 4 goals(chest,dark room,mother, beast)
  2. Player rolls a dice at the start of each run to determine which boss eden goes to.
  3. If you have a situation where you do not have key from two floors, and you have a streak to mother or 4 goals then I can few ways for how to continue the streak:
    1. You can go to the beast in this run and in the next run go to the mother
    2. Or just go to the chest and don't count this run in your streak.
